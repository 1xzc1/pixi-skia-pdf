# Pixi.js + Skia PDF Renderer

Приложение для рендеринга Pixi.js сцен с использованием Skia (CanvasKit) и экспортом в PDF.

## Возможности

- 🎨 Рендеринг Pixi.js контейнеров с использованием Skia WASM
- 📄 Экспорт сцен в векторный PDF
- 🖱️ Поддержка интерактивных событий (pointerDown, pointerUp)
- 🔄 Переключение между сценами
- ✨ Генерация случайных фигур
- 📊 Двойной рендеринг (Pixi.js + Skia canvas)
